# lhg-fm-reconcile：三表勾稽三硬关系

> 目标：让"表不平"从玄学变成清单。核心纪律：**三条勾稽关系每年必验，不平不许交付**。
> 插件审计脚本 `reconcile_audit.py` 把这三条做成了确定性规则（FM-BS-001/FM-RE-001/FM-CF-001）。

## 1. 何时使用

- 三表搭完 → 全流程校验
- 审计脚本报了 blocker → 直接看第 4 步修复手册
- 用户拿来一套现成的表说"帮我看看对不对"→ 只跑三条勾稽，不评价假设

## 2. 第一条：资产 = 负债 + 权益（FM-BS-001）

```
总资产 ＝ 总负债 ＋ 股东权益
```

- **每年都要平**，不是只平最后一年。
- 容差：相对 0.1%。差 1 块钱也算不平——先修公式，别调容差。
- **不平时的排查顺序**（按概率）：
  1. 权益侧：期末留存收益更新了吗？（新手第一大坑）
  2. 资产侧：现金是倒挤的还是拍的？（拍的必不平）
  3. 负债侧：借款变动记了吗？分红在负债侧挂了吗？
  4. 是不是手工改了某个数凑数？（git diff 看出来，改回去）

## 3. 第二条：留存收益滚动（FM-RE-001）

```
期末留存收益 ＝ 期初留存收益 ＋ 净利润 − 现金分红
```

- 这是利润表和资产负债表之间的"桥"。
- **常见坑**：
  - 分红在利润表扣了一次、BS 又扣一次 → 滚出来少一块
  - 第 1 年的"期初留存收益"没填（用上年实际数，别空着）
  - 净利润为负时，留存收益减少是对的，别当成错误去"修"
- 排查：把三年的"期初/净利润/分红/期末"列成表，一眼看出哪年断的。

## 4. 第三条：现金流勾稽（FM-CF-001）

```
现金净增加额 ＝ 经营活动现金流 ＋ 投资活动现金流 ＋ 筹资活动现金流
现金净增加额 ＝ 期末现金 − 期初现金
```

- 两个等式**同时成立**才算过。
- **常见坑**：
  - 营运资本变动符号反了（应收增加是现金流出，记减项）
  - 资本开支在投资活动里记成正数（流出记负）
  - 期初现金用了预测数而不是上年实际数
- 排查：先验第二个等式（简单），再验第一个；第一个不过，逐项看三类现金流的符号。

## 5. 修复手册（按报错查）

| 审计报错 | 先查 | 再查 | 最后查 |
|---|---|---|---|
| FM-BS-001 资产≠负债+权益 | 留存收益滚动 | 现金是否倒挤 | 有无手工凑数 |
| FM-RE-001 留存滚动不平 | 分红是否记两次 | 期初留存是否为空 | 净利润符号 |
| FM-CF-001 现金勾稽不上 | 营运资本符号 | 资本开支符号 | 期初现金口径 |
| FM-ASSUMP-001 假设缺失 | assumptions.csv 六项 | 值是否为小数口径 | 回 lhg-fm-assumption 补 |

**修复纪律**：每个修正都要有依据（公式错了修公式，假设错了回假设表）；**不许为了平表手工凑数**，凑出来的表审计过了、业务上是错的。

```
勾稽校验报告（模型目录：./model）
- FM-BS-001 资产=负债+权益：✅ 5 年全平
- FM-RE-001 留存收益滚动：✅

- FM-ASSUMP-001 假设完整：✅
- FM-IS-001 毛利润复算：⚠️ warning（2028 年偏差 1.2%，原因为手工调整成本，已标注）

```

## 7. 反模式（不许这么干）

- ❌ 表不平，调大容差让它"过"
- ❌ 加一个"调节项/其他"把差额塞进去
- ❌ 只验最后一年，中间年份不平不管
- ❌ 修复时直接改 statements.csv 的数字，不更新假设或公式依据
- ❌ blocker 没清零就交付，说"差不多平了"

## 8. 常见问题

- **Q：差 0.5 元，四舍五入导致的？** A：先确认是四舍五入（把公式展开看两位小数）；确认后把容差说明写进校验报告，不算 blocker——但要在报告里写清楚。
- **Q：用户说"差不多就行了"？** A：不行。勾稽是建模的底线，底线没有"差不多"。修好再交付，最多 10 分钟的事。
- **Q：三年都平，就一年不平？** A：看那一年的特殊事项：是不是当年有大额分红/增资/资产处置。特殊事项单独列示，别硬塞进常规公式。
- **Q：审计脚本和手工验的结果不一致？** A：以脚本为准，先检查手工验的公式；脚本逻辑见 `scripts/audit/reconcile_audit.py` 注释，规则都是按本 skill 写的。
- **Q：三年都平，就一年不平？** A：看那一年的特殊事项：是不是当年有大额分红/增资/资产处置。特殊事项单独列示，别硬塞进常规公式。
- **Q：BS 平了，但现金和 CF 对不上？** A：说明 BS 的现金是拍的、CF 是算的——两边用的不是同一套逻辑。修法：现金改倒挤（期末现金 = 期初 + 净增加），重跑。
- **Q：分红到底记在哪？** A：利润表不扣分红（净利润是扣税后、分红前）；BS 权益侧扣（留存收益公式里减）；CF 筹资活动记流出。三处各记一次，缺一不可。
- **Q：增资/减资怎么过勾稽？** A：增资：BS 股本增加、现金增加；CF 筹资活动记流入。三处联动，缺一处就不平。减资反向。
- **Q：资产处置收益（卖设备赚了一笔）？** A：利润表单独列"资产处置收益"（不许混进营业利润）；BS 固定资产减少、现金增加；CF 投资活动记流入。勾稽照样三条全过。

## 8. 附：三分钟手工验算法

没跑脚本时，拿计算器 3 分钟验完：

```
第 1 步：BS 行：总资产 − 总负债 − 股东权益 = 0？（每年）
第 2 步：期末留存 − 期初留存 − 净利润 + 分红 = 0？（每年）
第 3 步：期末现金 − 期初现金 − 现金净增加 = 0？
第 4 步：现金净增加 − 经营 − 投资 − 筹资 = 0？
```

四步全 0 → 勾稽过；哪步不是 0 → 按第 5 步修复手册查那一类。

**验算口径**：金额单位统一（元/万元二选一，全表一致）；单位混用是手工验算第一大坑——验之前先看表头有没有写单位。

**验算频率**：三表每改一次，四步重验一次。别攒到最后一起验——攒着验，不平的时候你分不清是这次改错的还是上次就错的。

**多人协作**：一个人搭 IS、一个人搭 BS 时，每天对一次勾稽。分工不设"最后统一平表"的人——平表是每个人的事，不是收尾工作。
